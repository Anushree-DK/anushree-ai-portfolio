# Anushree D K — AI/ML Portfolio

A polished Streamlit portfolio for AI/ML and LLM engineering applications.

## What it demonstrates
- LLM/RAG engineering
- Semantic search and embeddings
- FastAPI/backend experience
- Production-oriented AI design
- Interactive property-document RAG prototype
- Professional experience presented without exposing employer-confidential code/data

## Run locally
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy
Push the folder to a GitHub repository, then deploy `streamlit_app.py` with Streamlit Community Cloud.

Suggested repo: `anushree-ai-portfolio`
Suggested public URL: `anushree-ai-portfolio.streamlit.app`
