# Anushree D K — AI/ML Portfolio

A recruiter-facing Streamlit portfolio with:

- Professional experience and production AI work
- Interactive AI Lab
- PropertyPilot agentic project showcase
- Resume intelligence demo
- Clean multipage navigation

## Run

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Portfolio structure

- Home
- Experience
- AI Lab
  - PropertyPilot
  - Resume Intelligence
- Resume
- Contact

PropertyPilot is presented as a personal project using synthetic/sample data. Aritrak systems such as EIOS and Smart Recruit remain under Professional Experience and are not presented as publicly runnable employer systems.


## Visual design

The hero includes the supplied professional profile photo with subtle floating motion, animated background grid and ambient orbs.
